# NBT 路径规则

## 概述

NBT 路径用于定位一个 NBT 结构中的某个（或某些）标签，支持在 **Compound** 中按名称访问，以及在 **List / Array** 中按索引访问。  
路径采用类似文件路径的语法，以 `/` 作为步分隔符，并通过双引号机制允许键名包含任意字符。

---

## 路径基本结构

路径由若干 **步（step）** 组成，步之间以 `/` 分隔。

- 每一步**只属于以下两者之一**：
  - **名字步**：选取 Compound 中指定名称的子标签。
  - **索引步**：选取 List / Array 中指定索引（或索引范围）的元素。
- 不允许将名字与索引合并为一步（如 `foo[0]`），必须分开为两步 `foo/[0]`。

### 名字步

名字步用于在 Compound 中定位子标签。有两种写法：

| 类型       | 语法                                             | 说明                                                                                 |
|------------|--------------------------------------------------|--------------------------------------------------------------------------------------|
| 普通名字   | 不包含 `/`、`[`、`]`、`"`、`\` 的非空字符序列    | 直接书写，无法表示特殊字符、空键名或含转义的内容                                     |
| 引号名字   | `"` 包裹的任意字符序列，内部支持转义              | 当键名包含 `/`、`[`、`]`、`"`、`\`，或是空字符串时，**必须**使用此形式               |

**重要约束**：  
- 引号名字**必须**以 `"` 开头并以 `"` 结尾，不允许中途出现未转义的双引号导致提前闭合。  
- 普通名字内部**禁止**出现 `"` 或 `\`，解析时遇到这些字符（且未开启引号模式）即视为语法错误或名字终止。

**转义规则（仅引号名字内部生效）：**

| 转义序列 | 实际字符 |
|----------|----------|
| `\"`     | `"`      |
| `\\`     | `\`      |

任何其他 `\X` 组合均为非法，解析器应报错。

### 空键名

空字符串键名**只能**通过引号名字 `""` 表示，不允许用连续分隔符 `//` 等隐式方式表达。

### 索引步

索引步用于在 List / Array 中选取元素。**只允许作为独立的步出现**，语法为：

- `[N]` – 选取索引为 `N` 的单个元素（`N` 为非负整数）。
- `[N..M]` – 选取索引从 `N` 到 `M` 的所有元素（闭区间，`N ≤ M`，均为非负整数）。
- `[N..]` – 选取索引从 `N` 到列表末尾的所有元素（包含 `N`）。
- `[..M]` – 选取索引从开头（`0`）到 `M` 的所有元素（闭区间，包含 `M`）。
- `[]` – 选取列表中的**全部元素**（等价于 `[0..]` 或 `[..最后索引]`）。

索引步**不能**与名字步组合（如 `foo[0]` 非法，应写为 `foo/[0]`）。  
索引步**必须**以 `[` 开头并以 `]` 结尾，中间只能出现数值与至多一个 `..`，否则视为语法错误。  
**强制规则**：访问 List / Array 内部元素时，**必须显式写出索引步**；任何 List / Array 后如果路径未结束却直接出现名字步，属于语法错误。

---

## 路径求值规则

1. 从根标签开始，依次处理每个步。
2. 若当前标签为 **Compound**：
   - 必须遇到**名字步**，根据名字获取子标签，进入该子标签。
   - 若遇到索引步，则为错误（Compound 不可按索引访问）。
3. 若当前标签为 **List 或 Array**：
   - **若路径在此结束**（无下一步），则当前选中的是整个 List / Array 标签本身。
   - **若路径未结束**，则下一步**必须**是索引步，否则报错（不允许直接跟名字步）。
   - 遇到索引步时，按照索引步规则选出元素（单个或范围）。若选出多个元素，后续路径将**分别应用于每个匹配元素**。
4. 若当前标签为基本类型（如 String、Int 等），则路径不应再有后续步，否则为错误（无法深入）。
