# NBT 路径规则

## 概述

NBT 路径用于定位一个 NBT 结构中的某个（或某些）标签，支持在 **Compound** 中按名称访问，以及在 **List / Array** 中按索引访问。  
路径采用类似文件路径的语法，以 `/` 作为步分隔符，并通过双引号机制允许键名包含任意字符。

---

## 路径基本结构

路径由若干 **步（step）** 组成，步之间以 `/` 分隔。

- 每一步**只属于以下两者之一**：
  - **名字步**：选取 Compound 中指定名称的子标签。
  - **索引步**：选取 List / Array 中指定索引（或索引范围）的元素。
- 不允许将名字与索引合并为一步（如 `foo[0]`），必须分开为两步 `foo/[0]`。

### 名字步

名字步用于在 Compound 中定位子标签。有两种写法：

| 类型       | 语法                                   | 说明                                                                 |
|------------|----------------------------------------|----------------------------------------------------------------------|
| 普通名字   | 不包含 `/`、`[`、`]`、`"` 的连续字符序列 | 可直接书写，无需特殊包裹                                             |
| 引号名字   | `"` 包裹的字符串，内含转义             | 当键名包含 `/`、`[`、`]`、`"` 或需要空键名时，必须使用此形式         |

**引号内的转义规则（仅两种）：**

| 转义序列 | 实际字符 |
|----------|----------|
| `\"`     | `"`      |
| `\\`     | `\`      |

任何其他 `\X` 组合（`X` 不是 `"` 或 `\`）均为非法，解析器应报错。

## 空键名

支持空字符串键名，在引号名字中写作 `""`。

### 索引步

索引步用于在 List / Array 中选取元素。**只允许作为独立的步出现**，语法为：

- `[N]` – 选取索引为 `N` 的单个元素（`N` 为非负整数）。
- `[N..M]` – 选取索引从 `N` 到 `M` 的所有元素（闭区间，`N ≤ M`，均为非负整数）。
- `[N..]` – 选取索引从 `N` 到列表末尾的所有元素（包含 `N`）。
- `[..M]` – 选取索引从开头（`0`）到 `M` 的所有元素（闭区间，包含 `M`）。

索引步**不能**与名字步组合（如 `foo[0]` 非法，应写为 `foo/[0]`）。  
如果在 List / Array 后没出现索引步，则相当于选中其中的全部元素。  

## 路径求值规则

1. 从根标签开始，依次处理每个步。
2. 若当前标签为 **Compound**：
   - 必须遇到**名字步**，根据名字获取子标签，进入该子标签。
   - 若遇到索引步，则为错误（Compound 不可按索引访问）。
3. 若当前标签为 **List 或 Array**：
   - **若下一步是索引步**：取出指定索引（或范围）的元素继续。如果索引步为范围，则后续步骤会**分别应用于每个匹配元素**。
   - **若下一步是名字步**：触发 **“索引全部”** 语义 —— 相当于对列表中的**每一个元素**分别应用该名字步。后续路径将并行地在每个元素内部执行。
   - **若路径在此结束**（无下一步），则当前选中的是整个 List / Array。
4. 若当前标签为基本类型（如 String、Int 等），则路径不应再有后续步，否则为错误（无法深入）。
